# sJIA / MAS Early Warning Platform · 重症并发症（MAS）动态预警平台

> 「罕见·无界」黑客松赛题 · 项目7：sJIA + 合并 MAS 动态预警平台
> 由 sJIA 守护者联盟发起，[OpenRD 罕见病开源社区（Khub）](https://github.com/OpenRDHub)共建 · 患者共创 · 一个赛题 = 一个长期开源项目

为慢病家庭打造重症并发症动态预警平台：串联分散的化验与症状信息，自动分析关键指标趋势，在风险持续上升的过程中**尽早提示**。

## 🧭 疾病背景

**幼年特发性关节炎全身型（sJIA）**：儿童期最复杂的疾病之一，以**发热、皮疹、关节炎**三大表现为特征，弛张热突出；年发病率约 0.3–0.8/10 万，已纳入中国第二批罕见病目录。16 岁以上患者可表现为成人斯蒂尔病（AOSD）。

**巨噬细胞活化综合征（MAS）**：继发性噬血细胞性淋巴组织细胞增多症（HLH），是一种严重且危及生命的过度炎症反应综合征，**是 sJIA 最严重的并发症**：

- 预计**至少 7%** 的 sJIA 患者病程中出现 MAS，还有更多患者仅表现部分临床特点而未被诊断；
- 一项 350+ 例 sJIA 相关 MAS 队列中**致死率可达 8%**；
- 典型表现：快速进展的持续发热、肝脾肿大、肝功能异常、出血、甚至多器官衰竭；
- **早期表现与 sJIA 疾病活动不易区分**，等指标完全符合诊断标准再干预往往延误治疗、增加难度。

**主流实验室诊断标准（2016 PRINTO / ACR / EULAR）**：确诊或疑似 sJIA 患者发热 + 铁蛋白 > 684 ng/mL，且具备以下任意 2 条：

- 血小板 < 181×10⁹/L
- 天门冬氨酸氨基转移酶（AST）> 48 U/L
- 甘油三酯 > 156 mg/dL
- 纤维蛋白原 < 3.6 g/L（360 mg/dL）

另有 HLH-2004 标准与 MAS/sJIA（MS）评分表可供参考（详见社区知识库《预警平台研发方案 v1.0》）。

## 🎯 为什么需要"动态预警"

早期发现 MAS **不依赖某一次检查结果，而需要密切观察指标的动态变化**。地方医生常因缺乏经验，等待指标完全符合诊断标准后再干预，一定程度上延缓治疗。因此本项目的核心定位是：**动态监测 + 连续预警**——帮助患者家庭和医生提高警惕、抓住时机。

## 🛠 平台设计设想（研发方案 v1.0）

- **静态监测**：输入单次化验指标 → 按诊断标准 / 评分表给出风险评估
- **动态监测**：输入 ≥2 次指标 → 追踪关键指标趋势，支持为指标设置权重；报警逻辑区分**核心指标**与**一般指标**，可设置预警灵敏度
- **静态 + 动态结合**：数据越多，预警越早、越准
