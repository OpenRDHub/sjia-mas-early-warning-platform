# sJIA / MAS Early Warning Platform · 重症并发症动态预警平台

> 项目7：sJIA + 合并 MAS 动态预警平台 —— [OpenRD 罕见病开源社区](https://github.com/OpenRDHub)

为慢病家庭打造重症并发症动态预警平台。

## 真实处境

来自 sJIA 病友的需求：像 MAS 这样的严重并发症进展快、风险高，早期变化却可能与普通疾病活动混在一起。

## 挑战方向

- 串联分散的化验与症状信息
- 自动分析关键指标趋势
- 在风险持续上升的过程中尽早提示

## 关键词

`sJIA（幼年特发性关节炎全身型）` `MAS（巨噬细胞活化综合征）` `动态预警` `指标趋势分析`
