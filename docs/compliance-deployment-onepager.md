# RareGuard 合规与落地一页纸

> 面向评审与患者顾问的"能不能真落地"说明。核心立场：**决策辅助工具，非诊断器械**；
> 风险结论 100% 出自确定性规则引擎，LLM 仅翻译表达。

## 1. 产品定位与红线（决定监管归属）

- 定位：家庭端**健康记录 + 趋势展示 + 就医提示**。不确诊、不给用药/剂量方案、不替代复诊。
- 硬红线（工程强制，非口号）：
  - 免责声明"AI 辅助参考，请以医生诊断为准"由**渲染层注入**，模型不可绕过；
  - 六层校验管道 L4 拦截"确诊/是…病/必须服药/剂量"等句式，命中即回退固定模板（fail-closed）；
  - 红色预警只引导"尽快就诊/联系主诊"，绝不给出治疗指令。

## 2. 监管边界与定性和谐

| 事项 | 结论 |
|---|---|
| 医疗器械（《医疗器械监督管理条例》+ AI 医用软件分类界定） | v1 定位为**不作为医疗器械管理的辅助记录/提醒软件**：不做疾病诊断、不输出治疗决策。若未来升级为"辅助分诊/诊断"，需走 NMPA 二类/三类注册路径——当前刻意不越线。 |
| 软件性质 | 通用 Web 应用（FastAPI + PWA），开源 Apache-2.0，可自部署。 |

## 3. 数据与隐私（健康数据=敏感个人信息）

- 适用法：《个人信息保护法》(医疗健康属敏感个人信息，需**单独同意**)、《数据安全法》、《网络安全法》、《未成年人网络保护条例》(监护人同意)。
- 最小必要：仅存 建档(pid/姓名/出生日期) + 化验值 + 打卡；真实样例只进本地 `data/real_samples/`，**.gitignore 不入公开仓库**。
- 去标识：演示与评测数据全部**合成**；对外展示用编号替代姓名。
- 上云边界：OCR 走魔搭 API-Inference（生态伙伴），**上传前提示家长授权、不附带可识别身份信息**；断网模式 OCR 走本地预跑缓存、叙述走确定性模板，**零外发**。
- 留存与删除：家长可查看/导出/删除；预警与操作写 WORM 审计（`verification/audit.py`）便于追溯。

## 4. 部署形态

- 家庭/院内单机：SQLite（`RAREGUARD_DB`），无需公网；`RAREGUARD_OFFLINE=1` 一键断网演示。
- 规模化：PostgreSQL + TimeSeriesProvider 只读抽象，预留多患儿/多机构扩展位（v1 不启用）。
- 一键门禁：`scripts/run_all_gates.py`（召回/OCR/红线/断网E2E/真实冒烟）保障每次交付质量。

## 5. 责任、免责与安全兜底

- fail-closed：任一校验不通过 → 回退保守模板文案，宁可提示就诊不可漏警。
- 人工确认通道：OCR 双通道不一致 → 标记"待核对"，家长确认后才入库，不自动采信。
- 紧急引导：红色预警附"急诊准备清单"，并提示按当地急救号码处置。
- 责任声明：产品为**信息组织与趋势提示**，最终诊疗判断归主诊医师。

## 6. 长期孵化与市场化路径（呼应"长期孵化/机会无界"）

1. **患者组织试点**：与 SJA 守护星星联盟合作，家属共创 → 小范围真实使用 → 口碑进病友群。
2. **医院随访工具**：作为风湿科随访依从性辅助（家长端记录 + 医生端一页纸），对接 LIS 自动取化验值。
3. **开源建信任**：Apache-2.0 + 可复现合成评测集 + 文献取值登记（`docs/references.md`），供同行审阅阈值依据。
4. **成本模型**：魔搭按量 token（参赛支持 500 美元/人）；断网降级把在线调用压到最低。

## 7. 风险登记（Top）

| 风险 | 影响 | 缓解 |
|---|---|---|
| 真实样例 OCR 准确率未证 | 录入可信度受质疑 | 本周对接联盟取 3–5 份脱敏样例，跑 `real_ocr_eval` ≥95% |
| 阈值未经临床验证 | 假阳/假负 | 医生共创复核（见访谈提纲 §4） |
| 被误读为"诊断" | 合规/信任 | 渲染层免责 + L4 拦截 + 定位声明 |
| 敏感健康数据泄露 | 法律/声誉 | 本地/私有部署、去标识、断网零外发、WORM 审计 |
