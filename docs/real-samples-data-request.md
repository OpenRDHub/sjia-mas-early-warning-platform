# 真实脱敏样例数据需求清单（赛题 04 · sJIA 预警模型）

> 用途：向主办方申请真实脱敏化验单样例，用于 OCR 字段级准确率评测（门禁 ≥95%）与
> 高危趋势形态验证。对应评测脚手架：`evals/real_ocr_eval.py`（样例就绪后运行
> `python -m evals.real_ocr_eval` 即产出报告）。
>
> 提出方：守望 · RareGuard 队（单人队，GitHub 提交见官方仓库 PR）
> 日期：2026-09-25

## 1. 数量与分布

- 3–5 位患儿即可；每位最好有 **2–3 次连续时间点的化验单**（如间隔 1–2 周），用于验证趋势预警（R-B 斜率规则）。
- 覆盖两类形态：
  - sJIA 病情活动期化验单；
  - **疑似/确诊 MAS 的异常化验单**（铁蛋白显著升高等）至少各 1 份。
- 只收正常单无法验证"不漏报"（召回 100% 门禁），异常形态样例是本需求的核心。

## 2. 载体格式

- **手机拍摄的纸质化验单照片**为最理想形态（含真实场景的倾斜、反光、折痕），PDF/扫描件转图也可。
- PNG/JPG；短边 ≥1080 像素；单文件 ≤10MB。
- 评测脚本目前读取 `data/real_samples/*.png`，JPG 可现场适配，成本极低。

## 3. 化验单需包含的项目（有多少给多少，不强求齐全）

| 项目 | 规范代码 | 可接受单位 |
|---|---|---|
| 血清铁蛋白 | ferritin | ng/mL、μg/L |
| C 反应蛋白 | crp | mg/L、mg/dL |
| 红细胞沉降率（血沉） | esr | mm/h |
| 血小板计数 | plt | ×10⁹/L |
| 纤维蛋白原 | fib | g/L、mg/dL |
| 谷丙转氨酶 ALT | alt | U/L、IU/L |
| 谷草转氨酶 AST | ast | U/L、IU/L |
| 甘油三酯 | tg | mmol/L、mg/dL |
| 体温（打卡项，非化验单） | temp | ℃ |

**参考区间和 ↑↓ 箭头请保留在图内**——我们做 OCR 双通道校验（数值通道 + 箭头通道互证）依赖这些信息。

## 4. 脱敏要求

- 必须删除：姓名、病历号/就诊卡号、医院名称、出生日期、家长姓名、身份证号等一切直接标识符。
- 保留/替换：
  - 患儿年龄段（如"6岁"）与性别可保留；
  - 用**假名编号（如 S001）代替姓名**，同一患儿的多次化验单用同一编号串联；
  - 日期可整体平移，但需保持同一患儿的**相对时间间隔**不变（趋势评测依赖）。

## 5. 配套真值

- 理想：每张图附一份人工核对的指标真值表（项目名 + 数值 + 单位），JSON 或表格均可。
- 若主办方无暇整理，我方可自行登记真值后**请风湿科医师复核确认**，请主办方确认可接受此方式。
- 收到数据后评测脚本自动产出字段级准确率报告（`mean_accuracy`，门禁 ≥95%），结果可回馈赛事方作为共创证据。

## 6. 合规承诺

- 样例**仅用于离线评测与演示**，绝不上传 GitHub 仓库（赛事规则明确患者隐私排除在开源范围外；`data/real_samples/` 已列入 `.gitignore`）。
- CLA 与患者数据保密协议可先行签署，再接收数据。
- 接收渠道建议：飞书群文件/共享网盘；本地仅存评测目录，评测结束后可按主办方要求销毁并回执。
