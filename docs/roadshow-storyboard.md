# RareGuard 路演分镜脚本（10 分钟）

对应 spec §4.2 故事线。每拍 = 操作 + 预期屏上状态 + 一句话话术。演示全程可断网（见 `docs/rehearsal-checklist.md`）。

准备：`RAREGUARD_OFFLINE=1 python -m rareguard.api.home_server`（端口被占则换 `--port 8010`），浏览器开首页，患儿编号填 `PREH` 建档。参赛主路径只有家庭端，不要起基座预问诊服务。

**证据口径（开口可复述）**：**合成留出是回归门禁，不是临床金标。** 召回/提前量数字来自合成集 **N=6**（2 例 MAS 前驱 + 4 例正常对照），不是真实患儿金标。

## 收尾与孵化（45 秒）
> 话术（进行时；未完成绝不谎报人数或「已对真实患儿验证」）：
>
> "这套阈值不是我们关在屋里拍的。我们按**患者共创**的赛事理念，正在通过 **SJA 守护星星联盟**
> 转介家长和风湿科医生做结构化访谈与可用性走查——访谈提纲与知情同意已就绪，招募进行中。
> 合成化验单 OCR 字段准确率 ≥98% 只说明录入链路可回归；真实脱敏样例到位后才会跑
> `evals/real_ocr_eval.py` 出报告，**现在不能把合成数字说成已对真实患儿验证**。
>
> 合规上，RareGuard 定位是**家庭健康记录 + 趋势提示**，自主性光谱停在 **L1 辅助预警**
> （规则主权，不坐诊）；不确诊、不给剂量。健康数据按《个人信息保护法》走单独同意、最小必要、本地/私有部署，
> 断网演示**零外发**，所有预警写 WORM 审计。开源 Apache-2.0，取值文献逐条可查。
>
> 下一步：患者组织试点 → 风湿科随访工具 → 对接院内 LIS 自动取化验值（点对点，不做 FHIR 全量）。"

## 一句话弹药（随处可插）
- 共创："和真正半夜守着孩子数体温的家长一起做，不是替他们想。联盟转介进行中。"
- 验证："合成留出是回归门禁，不是临床金标。真实脱敏样例 OCR 报告等供样后再报数字。"
- 档位："没开早提示就是 HLH-2004 严格档，不要叫 PRINTO；勾上才是 2016 敏感档，只升不降。"
- 合规："只提示就医、不碰诊断，红线是**代码强制**的，不是嘴上说的。"
- 隐私："演示断网零外发；健康数据本地/私有部署，最小必要 + 单独同意。"
- 信任："开源 + 文献取值登记 + 审计日志，同行可以逐条审我们的规则依据。"

## 常见提问应答
- **"会不会误诊/担责？"** — 系统不确诊、不给剂量，输出强制"以医生诊断为准"，结论 100% 来自可审计的确定性规则。
- **"LLM 出错怎么办？"** — 校验管道：越界输出被护栏拦截回退模板；宁可误拦不可漏放。输入净化是 V1/`input_guard`，不要和产品「自主性 L1」混为一谈。
- **"凭什么是你？"** — 基座是已上线的医疗级验证架构，评测门禁 + WORM 审计是套壳队伍没有的壁垒。预问诊三页是基座遗留，**不是**本赛题演示主路径。
- **"患者/医生参与了吗？怎么验证的？"** — 共创进行中（提纲见 `docs/patient-cocreation-interview-guide.md`）。合成 N=6 门禁已绿；真实 OCR/访谈数字未到齐前不报完成人数。
- **"健康数据合规吗？算不算医疗器械？"** — 定位为记录+趋势提示、不做诊断，落在非器械边界内；PIPL 单独同意/最小必要/本地部署/断网零外发/WORM 审计（详见 `docs/compliance-deployment-onepager.md`）。
