## 一句话弹药（随处可插）
- 共创："和真正半夜守着孩子数体温的家长一起做，不是替他们想。"
- 验证："指标不靠自说自话——真实脱敏样例 OCR ≥95%，脚本现场可复跑。"
- 合规："只提示就医、不碰诊断，红线是**代码强制**的，不是嘴上说的。"
- 隐私："演示断网零外发；健康数据本地/私有部署，最小必要 + 单独同意。"
- 信任："开源 + 文献取值登记 + 审计日志，同行可以逐条审我们的规则依据。"

## 常见提问应答
- **"会不会误诊/担责？"** — 系统不确诊、不给剂量，输出强制"以医生诊断为准"，结论 100% 来自可审计的确定性规则。
- **"LLM 出错怎么办？"** — 六层校验：越界输出被 L4 拦截回退模板；宁可误拦不可漏放。
- **"凭什么是你？"** — 基座是已上线的医疗级验证架构，评测门禁 + WORM 审计是套壳队伍没有的壁垒。
- **"患者/医生参与了吗？怎么验证的？"** — 见收尾：SJA 守护星星联盟转介做结构化访谈 + 可用性走查校准阈值与文案；真实脱敏样例跑 OCR≥95%（方法见 `docs/patient-cocreation-interview-guide.md`）。
- **"健康数据合规吗？算不算医疗器械？"** — 定位为记录+趋势提示、不做诊断，落在非器械边界内；PIPL 单独同意/最小必要/本地部署/断网零外发/WORM 审计（详见 `docs/compliance-deployment-onepager.md`）。
