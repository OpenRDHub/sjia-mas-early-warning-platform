## 1. 产品定位

面向 SJA（全身型幼年特发性关节炎）患儿家庭的**并发症（MAS）动态预警 Web 应用**。家属拍照上传化验单 + 每日 30 秒症状打卡，系统以**纯规则时序引擎**识别风险爬升，分级推送预警；LLM 仅将规则结论翻译为通俗表达，**不参与任何风险判断**。

**非目标**：不做确诊、不给用药方案、不替代复诊、v1 不做多患者管理、不做原生 App。

## 2. 总体架构

```
家属端 Web PWA（手机/电脑）
  首页风险仪表盘 │ 拍照录入 │ 每日打卡 │ 预警详情
        ▼
FastAPI 网关（复用 api/，角色裁剪 + 审计埋点）
        ▼
接入层
  ├─ OCR 解析服务（新）：Qwen-VL（魔搭 API）→ JSON Schema 结构化化验值
  │    双通道校验：同一化验单两次独立解析，字段不一致 → 要求人工确认
  └─ 打卡表单（新）：发热/关节痛/皮疹/疲劳/出血点/腹痛/头痛/呕吐 8 项（0-10 VAS + 有无）
        ▼
数据层（新）
  patient / lab_panel / lab_item / daily_checkin / alert / audit_log
  SQLite（开发）→ PostgreSQL（演示与部署）；复用 BaseEHRProvider 抽象新增 TimeSeriesProvider
        ▼
分析引擎
  ├─ 规则趋势引擎（扩展 risk/rules.py，不经 LLM）
  │    R-A 绝对阈值：铁蛋白>500 ng/mL、FIB<1.5 g/L、PLT 较基线降>30%、
  │        ALT>2×ULN、TG>3 mmol/L、体温>38.5℃ 持续、ESR 骤降而 CRP 高（血沉-CRP 分离）
  │    R-B 斜率规则：CRP/铁蛋白连续≥3次上升、PLT+FIB 同向下降组合、ESR/PLT 比值漂移
  │    R-C MAS 风险分：HLH-2004 八项标准简化为家庭可得分项（发热天数/铁蛋白/血细胞/
  │        甘油三酯/FIB/转氨酶/ESR/症状项），输出 0–100 分 + 趋势箭头
  └─ AI 叙述层（LLM）：输入=规则结论+接地数据，输出=家长版解释+行动建议模板
        ▼
安全层 六层校验管道（复用 verification/，L4 护栏词表替换为家庭版红线）
  家庭红线：禁止出现"确诊/是/不是…病"句式、禁止剂量建议、所有输出强制
  "AI 辅助参考，请以医生诊断为准"（前端渲染注入，模型不可绕过）
        ▼
预警分发
  红（风险分≥70 或命中 2 项高危规则）：页面强弹窗 + 急诊准备清单
  黄（40–69 或单项命中）：建议 48h 内复诊卡片
  绿（<40）：继续观察；全部预警写审计（fail-closed）
降级路径：魔搭 API 不可用 → 规则引擎照常出分，叙述层回退固定模板文案；
  OCR 不可用 → 结构化手工录入表单兜底。
```

**核心设计决策**：风险结论 100% 出自确定性规则，可单测、可回归、可离线——这是与"套壳 LLM 演示"队伍的本质差异，也是路演回答"可靠性"提问的核心弹药。

## 3. 数据与算法

### 3.1 合成数据集（同时充当评测集）
- 6 名虚拟患儿 × 180 天：4 例全程波动正常 + 2 例在第 90/150 天发生 MAS（发作前 7–14 天指标按典型漂移曲线爬升）。
- 参数依据公开文献（HLH-2004 诊断标准、MAS 分类标准 Ravelli 2016 等），`docs/references.md` 逐条登记出处与取值依据。
- 合成脚本 `synth/generate_dataset.py` 开源可复现，随机种子固定。

### 3.2 真实样例（并行申请）
- 报名后通过主办方链接 SJA 患者组织，获取 3–5 份脱敏化验单图片，仅用于验证 OCR 字段准确率（目标 ≥95%），**不进公开仓库**，本地 `data/real_samples/`（.gitignore）。

### 3.3 OCR 契约
- 提示词强制输出 JSON Schema：`{项目名, 结果值, 单位, 参考区间[low,high], 异常标记}`；
- 单位归一化表（ng/mL↔μg/L 等）；参考区间冲突时以报告单标注的院内区间为准；
- 双解析不一致的字段进入"人工确认"队列，UI 高亮待核对。

## 4. 产品与路演

### 4.1 家庭端四屏
1. **仪表盘**：红绿灯 + 90 天风险分趋势曲线 + 关键指标迷你图；
2. **拍照录入**：相册/相机 → 解析结果逐字段确认 → 入库；
3. **每日打卡**：8 项量表 30 秒完成，连续打卡天数激励；
4. **预警详情**：分级卡片 + 通俗解释 + **"给医生看的一页纸摘要"导出**（PDF，含趋势图与异常值表；可裁剪项）。

### 4.2 路演故事线（10 分钟）
SJA 病友真实痛点（引赛题原文）→ 现场拍照→10 秒结构化→趋势曲线→MAS 风险分爬升→红色预警弹窗→"这一页纸带到急诊能救命"→ 技术壁垒（六层校验+评测门禁，源自医疗级架构）→ 孵化路径（与基层 AI 问诊平台同源复用，患者共创迭代计划）。

### 4.3 开源交付
Apache-2.0；README 含架构图、评测结果表、合成数据脚本与复现说明，使其他患者组织可自部署。

## 5. 评测与发布门禁（继承 evals/ 框架）

| 指标 | 门禁 | 说明 |
|---|---|---|
| MAS 发作召回 | 100%（合成集 2 例均须发作前 ≥48h 报黄） | 未达 = 阻断发布 |
| 误报率 | ≤1 次 / 患者·月（4 例正常轨迹上统计） | |
| OCR 字段准确率 | ≥95%（真实样例，人工核对） | 合成样例 ≥98% |
| 红线违规 | 0（对抗集：诱导确诊/剂量/恐慌表述） | 命中即拦截并记审计 |
| 离线可用性 | 断网下规则引擎+模板文案全功能演示 | 现场彩排必测 |

## 6. 风险登记

| 风险 | 等级 | 缓解 |
|---|---|---|
| 现场网络不可靠 | 高 | 全链路离线演示包（预跑缓存+降级路径），彩排断网测试 |
| 单人工期 | 中 | 一页纸 PDF、多患者管理、语音输入 = 明确可裁剪项，砍了不影响门禁 |
| 医学规则正确性 | 中 | 每条规则登记文献出处；路演声明"患者共创阶段由风湿科医师审核"；合成集先行回归 |
| 数据合规 | 低 | 全程合成/脱敏演示数据；真实样例不入仓库；PII 扫描层已继承 |
| 魔搭 API 限流 | 低 | $500 Token 额度 + 本地 OpenAI 兼容端点备选（llm/provider 抽象现成） |
